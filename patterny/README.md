# Лабораторные работы по Python

Репозиторий курса «Паттерны объектно-ориентированного программирования на Python».
Каждая лабораторная работа находится в отдельной папке.

```text
lesson-01/   # первая лабораторная: решения, задания и тесты
lesson-02/   # функции, декораторы, генераторы и классы
lesson-03/   # отношения объектов, наследование, композиция и абстрактные классы
lesson-04/   # Singleton, Factory Method и Abstract Factory
```

В каждой папке сохранены условия заданий и добавлены решения в `tasks/`
и `homework/`. Подробности:

- [Лабораторная 1](lesson-01/README.md) — 36 аудиторных и 20 домашних заданий.
- [Лабораторная 2](lesson-02/README.md) — 36 аудиторных и 20 домашних заданий.
- [Лабораторная 3](lesson-03/README.md) — 42 аудиторных и 20 домашних заданий.
- [Лабораторная 4](lesson-04/README.md) — 36 аудиторных и 20 домашних заданий.

Структура и исходные README лабораторных 2–4 сохранены из архивов.
Они описывают учебные заготовки; решения находятся в Python-файлах.

## Запуск тестов первой лабораторной

Требуется Python 3.10+. Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r lesson-01/requirements.txt
python -m pytest -q
```

Для запуска из папки лабораторной:

```bash
cd lesson-01
python -m pytest -q
```

Условия заданий и подробная структура первой лабораторной описаны в
[`lesson-01/README.md`](lesson-01/README.md).

## Работа с лабораторными 2–4

Дополнительные зависимости не нужны. Запускайте Python из папки выбранной
лабораторной, чтобы её пакеты `tasks` и `homework` были доступны для импорта:

```bash
cd lesson-04
python -i -m homework.h01_intro
```

Примеры вызовов приведены в условиях функций и классов. Исходников автотестов
в архивах лабораторных 2–4 нет.
